# 外置写作规划（CZGH 测试版）

独立 API 根据酒馆当前完整请求生成写作规划，再把规划注入本轮正文请求。规划不写入聊天楼层。正文保留原预设要求的状态栏、顶栏、时间戳、摘要及其他附加内容；不会统一禁止状态栏。

当前为 0.1.1 原型，已核对 SillyTavern 1.18.0 的请求事件和上下文设置接口，尚未在用户酒馆及真实 API 上联调，不作为正式版发布。

## 安装和使用

在酒馆扩展安装界面使用测试仓库 `https://github.com/Zyzyzy-Dev/CZGHCS`。也可将本目录放入酒馆用户扩展目录并刷新。

1. 展开「外置写作规划」设置。默认关闭。
2. 输入独立 OpenAI-compatible API 基础地址（通常以 `/v1` 结尾）、模型与密钥。请求经酒馆后端发送，服务地址必须能被酒馆服务器访问。
3. 密钥仅保存在当前页面内存，刷新后重填，不保存至配置或仓库。
4. 标签默认「自动跟随本轮预设」：每次从已组装请求的 system/developer 指令中识别明确的规划标签，保持原标签大小写。已用两份本地预设验证：小冰块 5.5 自改版识别为 `<Abstract>`，V3.84 为 `<Think>`。不是固定标签，也不会读取下载目录来决定当前预设。
   自动识别采用保守规则，并非通用语义理解：标签仅出现在 assistant 预填、使用非 XML 标签、或指令表达复杂时可能识别失败；存在多种候选也会停止并提示。此时选择「手动指定」。不会静默回退为 `<Abstract>`。
5. 按需要调整规划和正文引导，再启用。整个本轮上下文（含记忆和图片，如有）会送到指定规划 API。
6. 正常发送消息。规划成功后正文自动继续，规划预览可在扩展面板查看。

失败、超时、停止或切换聊天时中止本轮，不自动重试计费。可重新发送，或点击「下次跳过规划」后重新发送，使用原始预设。跳过不会重用旧规划。

## 预设适配

默认保留完整上下文，末尾加入阶段引导，要求只生成规划或只执行已完成的规划。模型遵循效果需要实测；不保证仅靠追加指令就能覆盖每个预设中的强制规划要求。

高级精确替换规则只作用于**正文请求副本**里的 system/developer 文本，不修改已保存预设、用户输入或历史 assistant 消息。例如：

```json
[{"find":"在正文前需先交付一份供用户查看的写作准备稿，再开始写故事正文。","replace":"本轮写作准备稿已提供，请据此完成故事及原本要求的附加内容，不重复展示准备稿。"}]
```

包含 assistant 预填或混杂式规划引导的预设可能仍重复输出规划，需后续专门适配；当前不会批量删除标签之间的内容，以免误删世界书、历史或状态栏规则。

从 0.1.0 升级：旧默认 Abstract 配置自动切换为自动识别；旧版手动填写的其他标签保留为手动模式。识别结果仅用于当前请求，不写回固定标签，切换预设后重新识别。预览与注入内容均保留识别到的标签。

## 插件兼容依据

- 柏宝书：检查版本 1.2.9，提交 `32dbb48`。使用 `setExtensionPrompt` 注入历史、状态、时间提示，并注册 `bbs*` 宏。此扩展从 `CHAT_COMPLETION_SETTINGS_READY` 读取已组装的 messages，复用酒馆已展开的内容，不重复调用宏、不读取私有记忆存储。检测到未展开的 `bbs*` 宏会停止并提示。
- 织幕：检查版本 0.2.5，提交 `a9dfd09`。监听正文生成结束、消息接收及渲染事件。此扩展直接调用酒馆后端进行规划，不调用 Generate、不发消息事件、不插入楼层，避免规划被当成正文。实际联合运行仍需验证。
- 2026-10-07 追加核对 SillyTavern `1.18.0` 标签（`51ad27fb86d39a3daca3adaa970375c9670c12df`）：`CHAT_COMPLETION_SETTINGS_READY` 在发送前被 await，上下文提供 `extensionSettings` 与 `saveSettingsDebounced`。源码核对不能替代完整实机联调。

## 当前边界

- 主请求限 Chat Completion；支持普通回复、重生成和 swipe。quiet、代写、续写及带工具调用的请求跳过。
- 规划 API 限 OpenAI-compatible 非流式文本返回；不依赖其私有推理字段。
- 在最终请求构建后追加规划，不重新运行世界书或宏，避免副作用；也不会自动重新裁剪上下文。因此须预留规划输入空间，长对话可能超出主模型上下文限制。
- 分组聊天、复杂 assistant 预填、不同后端对尾部 system 消息的转换，以及其他扩展晚于本扩展修改请求的情况，尚未实机验证。
- 测试通过不等于正文质量提升；需对相同上下文进行实际生成对照。

## 开发验证
