# 创作规划

独立选择预设、世界书和兼容插件资料，调用规划 API 生成公开写作规划，再将规划加入本轮正文请求。正文保留酒馆原配置中的状态栏等要求。

**测试仓库当前提供 0.4.0-dev.23 开发预览，不是正式发布版。** 新输入密钥已支持本机浏览器持久保存，API 方案选择会恢复；真实酒馆 1.18.0 API 联调尚未完成。正式仓库未同步本次更新。

## 界面与方案

从魔法棒菜单打开「创作规划」。右上角齿轮进入设置，太阳按钮切换跟随酒馆/亮色/暗色。

- 设置：选择酒馆当前连接、预设更新编辑器的只读 API 方案，或创作规划自有方案；设置输出额度、超时、插件兼容和楼内显示。
- API 方案：可复制已有密钥引用为本地方案，独立新建/覆盖/删除，不修改编辑器原方案；删除方案不删除共享密钥。新密钥单独存入 IndexedDB，方案只保存随机引用；留空覆盖时保留原密钥。打开面板和刷新后恢复上次选择；删除当前方案或密钥失效时要求重新选择/填写，不自动回退到酒馆连接。
- 预设：选择酒馆预设，显示柏宝箱分组与条目正文，保存独立开关方案。视觉分组不改变 prompt_order 的实际执行顺序。
- 世界书：显示全局、角色主/额外、聊天专属和用户角色世界书；可额外添加世界书，查看正文并保存书/条目开关方案。开启只表示参与扫描，不表示强制注入。
- 楼内显示：规划存入消息 extra，按 swipe 绑定，在对应用户消息下方的独立 iframe 内折叠展示，不追加到 mes，不作为后续对话历史发送；编辑正文后标为历史规划。

界面拥有独立 document 和 CSS，只从酒馆接收 `--SmartThemeBorderColor`、`--SmartThemeBlurTintColor`、`--SmartThemeBodyColor`、`--mainFontFamily`、`--monoFontFamily`。这是样式隔离，不是防御同源恶意插件的安全边界。

## 独立生成

插件冻结来源副本，使用本地开关和私有宏变量构造规划请求。标签取规划预设，歧义时停止并支持手动指定。正文请求只追加规划与正文引导，不把规划预设覆盖到正文预设。规划失败、超时、取消或切换聊天时停止正文，避免沿用旧规划。

兼容资料：柏宝书历史/状态/时间提示/向量召回注入；构画大纲/事件线/刻度注入。柏宝书参数宏通过公开只读 API 按需查询；未勾选时不读取宏资料。不会额外触发插件生成。

世界书使用从 SillyTavern 1.18.0 提取并隔离的扫描核心，保留主次关键词、常驻、递归、概率、预算、扫描深度、分组和计时语义。计时只保存到规划端私有 metadata；不调用宿主全局扫描事件。

## 当前限制

- 酒馆 1.18.0 的 `/api/secrets/write` 保存新密钥时必定激活该密钥。为避免影响正文连接，本开发版不调用此接口，也不使用先切换再恢复的方式。新密钥存于当前浏览器、当前网站地址的 IndexedDB，不随酒馆设置备份同步到其他浏览器/设备；清除网站数据会删除它。它不是加密保险箱，同源脚本及有权限访问浏览器数据的人仍可能读取。插件不把密钥返回到界面快照或写入方案设置。
- 当前连接仅接入已核对的 OpenAI-compatible 返回路径（custom/openai/openrouter/groq/deepseek）；外部方案仅支持 custom。其他连接明确报错。
- 独立组装暂未支持群聊角色轮换和原生附件转换，发现时停止；quiet、impersonate、continue 和工具轮次不触发规划。
- 世界书 outlet 位置、向量扫描、自动化和角色标签过滤暂未完成独立适配，选中相关项时明确报错，不静默改成普通注入。世界书正则和其他插件的 WORLDINFO_SCAN_DONE 钩子不复用。
- 宏覆盖目前为已验证的基础角色/用户/历史值、变量读写及柏宝书宏；不运行任意全局宏处理器；EJS 需开启独立兼容开关并安装 ST-Prompt-Template。未知双花括号内容按字面原样保留；已知插件宏缺失数据、变量名非法及宏未闭合仍会阻断，不能宣称兼容所有预设。
- 已有计划若使用不同模型，其真实 token 计算与模型最大上下文仍需实机核验；开发版使用所选预设额度及酒馆当前 tokenizer。

## 验证和开发

`npm test` 运行 Node 测试；`npm run check` 检查全部 src 模块。`tests/browser-check.mjs` 用本地模拟酒馆和假 API 检查三页交互、完整规划/正文分离、楼内绑定、HTML 文本安全、明暗主题、CSS 隔离和 390px 窄屏。

这些测试不代替真实酒馆 API 联调。私人预设仅在本机验证，没有纳入仓库。源码全部位于 `src`，文件头说明作用；`index.js` 为薄入口，`tests` 不参与运行。

扫描核心的来源和 AGPL-3.0 条款见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

### 0.4.0-dev.9 交互修正

分组开关仅控制读取，不批量改写组内开关。世界书先显示书名，展开后查看条目。预设/世界书方案菜单增加只读的当前酒馆来源，确认后载入独立副本，取消不改设置。上一版误批量切换的条目可通过载入当前酒馆来源恢复。

### 流式规划与显示位置

设置页的「流式生成规划」可开关并保存，默认关闭。流式文本实时更新面板预览，收到完整结束标记并通过标签校验后才注入正文请求。开启「在用户消息下显示规划」时，发送用户消息后即可展开楼内卡片，查看等待状态、流式增量及失败信息；部分规划和错误仅在当前页面保留，刷新后不恢复。完成的规划显示在对应用户楼层下；正文完成后仍按回复 swipe 保存规划记录，切换回复时展示对应版本，不改写用户或 AI 的 mes。

### 0.4.0-dev.9 实时楼内预览

楼内卡片随用户消息出现，流式生成时保持展开状态并更新内容，失败时显示错误，未完成的规划不会注入正文或写入历史。规划流式设置只控制独立 API，不改写正文的 stream、模型或采样参数；规划完成后的状态显示正文请求流式标志。标志开启不保证中转站逐块转发，仍需通过实际网络响应时序核对缓冲行为。

### 0.4.0-dev.10 规划范围与重新生成

规划引导要求按当前预设的已启用步骤及子问题完整输出，不新增总结、检查报告或结束宣言。预设明确要求的例句、预写片段、格式确认和状态核算仍属于规划，规划之外的正文与状态栏成品不在此阶段输出。旧版默认引导自动迁移，用户自定义引导保留；区块标签继续跟随预设。格式校验能拦截标签外内容和明确截断，但不等于已自动验证所有自然语言步骤都被回答。

发送消息、重新生成及生成新备选均重新调用规划 API；仅切换查看已存在的备选时展示对应规划，不额外请求。备选生成排除待替换回复后再计算历史宏；重新生成使用酒馆已经移除旧回复的历史，不重复删除。原有插件的记忆注入仍来自其公开接口，本插件不会擅自回滚其他插件的记忆状态。

### 0.4.0-dev.11 工作台与楼内操作

预设/世界书方案未选择时显示空白，选择的方案及当前独立开关随设置保存，刷新后恢复。修改后保留方案名称，并在方案栏下显示「改动未保存」；覆盖后显示「改动已保存」。当前酒馆来源只能载入或另存为新方案，不能覆盖/删除。载入、覆盖和打开面板时自动读取最新资料，移除手动刷新按钮。

顶部从左到右为停止本轮、规划预览、设置、外观、关闭。规划预览改为单独页面；用户楼层标题右侧也可停止尚在等待或生成的规划。监听消息发送、用户楼层渲染和楼层 DOM 插入，使卡片不依赖 API 首字返回。已用模拟 API 验证连续两轮：最新输入送入第二轮规划、新规划绑定最新用户楼层、上一轮记录保留；流式中取消不注入部分结果。

内置指令以通用规则区分资料读取/召回与成品生成，不针对特定预设的「不输出状态栏」措辞添加例外；仅执行已启用预设要求的步骤，不额外添加召回。

图标使用插件自有 SVG：覆盖为文档编辑、删除为垃圾桶、设置为齿轮。主面板和楼内使用同一个持久化外观设置，太阳/月亮/叶子分别表示日间/夜间/自适应；楼内外观按钮位于停止按钮左侧。

### 0.4.0-dev.12 图标交互

生成中显示带呼吸动效的双竖条，停止后恢复方块；减少动态效果偏好下不播放动画。眼睛按钮再次点击关闭预览，取消预览页返回按钮。齿轮重新绘制，已保存方案的覆盖与删除图标提高对比度。没有选择方案时修改条目不会自动新建，提示使用＋保存；只有已保存的自建方案可覆盖或删除。

### 0.4.0-dev.13 请求诊断与取消隔离

规划停止与正文停止分开：规划等待/生成阶段停止会同时取消尚未发出的正文请求；规划完成后插件停止入口不停止正文，正文使用酒馆原生停止功能。取消后立即重试或切换聊天时，迟到的旧请求不得停止新一轮或覆盖其结果。

楼内仅渲染最新用户消息对应规划，流式更新以约 60ms 合并发送，历史楼层不再创建 iframe；现有聊天 extra 记录不自动删除。眼睛预览页提供「生成结果 / 发送上下文」，上下文取实际发送给酒馆后端的 messages，按原始角色与顺序显示，并列出来源、模型、流式设置和输出额度。鉴权头、密钥字段不进入诊断；只在页面内存保留最近一次请求，切换聊天清空，不写入聊天或导出文件。酒馆后端可能继续转换请求，这不是供应商最终收包日志。

附件包含历史消息 extra.media、extra.image、extra.files 或 extra.file 对应的媒体/上传文件；尚未接入原生附件转换时明确停止。纯文本正文里的状态栏可直接作为历史文本读取，不属于附件。


### 0.4.0-dev.14 世界书位置和变量模板

支持作者注释之前/之后及示例消息前/后，蓝灯常驻和绿灯关键词继续经过原生扫描规则。作者注释按原始聊天设置与角色注释重建，遵守间隔、位置、深度和角色，避免混入正文阶段已注入的世界书；关闭作者注释或本轮未到间隔时，这两个位置不会注入。示例世界书按酒馆示例格式（角色名: / 用户名:）解析，并跟随已启用的示例标记。

自动读取酒馆助手 get/format_message/chat/character/preset/global_variable 宏所需的变量快照，支持点路径及简单数组/引号下标；对象移除 $ 内部字段，format 使用 YAML。重新生成备选时避开待替换回复的变量。只读变量，不调用 MVU parseMessage/replaceMvuData。

设置→插件兼容新增 EJS 模板兼容，默认关闭；开启后使用已安装 ST-Prompt-Template 的 prepareContext/evalTemplate 公共接口，组装后、预算核算前渲染消息。模板脚本在该插件环境中运行，可能产生自身副作用，不是只读沙箱。尚未适配 @@ 世界书激活指令、模板动态激活条目及全部第三方宏；已识别的未支持激活指令明确报错。没有真实 MVU 卡样本，本版接口模拟测试不代表所有变量卡已完成实测。


### 0.4.0-dev.15 声明式写作要求

规划引导不再将步骤限定为问答：声明式指导、必须/禁止项、节奏、篇幅、比例与格式约束也需在原步骤标题及编号下保留，并说明本轮落实方式。不得以情节安排替换原要求，或仅用“已知悉”等笼统确认。正文引导明确规划遗漏不解除原预设约束，也不在成品中新增执行清单。旧版默认规划引导自动迁移，自定义引导保留。

这项修正改善指令覆盖，并非语义完整性验证器。自动测试验证指令组装和迁移；实际模型是否完整执行仍需结合“发送上下文”和生成文本核对。


### 0.4.0-dev.16 非问题式指导原文保留

规划区块内的问题式引导逐项回答，非问题式指导和约束按宏展开后的原文逐字保留，沿用标题、层级、编号、否定词、数值及标签，不再改写为落实方案。混合子项保留指导原文并回答其中的问题；明确要求列举、计算、召回或预写的任务仍执行。规则不硬编码状态栏禁令，不复制整个预设或规划区块外的成品模板。该规则属于模型提示，尚非逐字一致性自动校验。


### 0.4.0-dev.17 复述不受宏来源限制

明确问题式引导逐项回答，非问题式引导直接复述。直接写在预设条目中的文本照录原文；涉及变量宏时使用展开后的实际文本。是否复述与是否使用宏无关，不在内置提示词中加入某个用户预设特有的状态栏禁令。


### 0.4.0-dev.18 原文要求与本轮安排分开

非问题式引导先逐字复述原文，再在同一子项内另起“本轮安排：”说明执行方式。安排不得替换原文，不得改变约束的作用对象、单位、范围、强度、条件或否定关系；具体定义遵循已启用预设，不编造硬性数值。问题式引导仍逐项回答。此项为提示词约束，未增加语义一致性自动校验。


### 0.4.0-dev.19 标签引用校验

修复规划内部以反引号引用完整开始/结束标签时误判为区块边界的问题；保留真实重复区块、嵌套、标签外正文和截断拦截。格式确认按原预设指定对象回答，不能用插件的规划包装格式替代正文成品格式要求。此修复不代表对规划内容完整性或逐字复述进行了语义验证。


### 0.4.0-dev.20 提取规划区块

返回文本允许有区块外内容；提取当前预设标签对应的第一个完整、非空、无嵌套区块，正文上下文只注入该规划及其首尾标签，不注入前言、尾文、自检或后续区块。精确反引号标签引用不作为边界。缺失闭合、空区块、真实嵌套及接口报告 length 截断仍停止；此规则替代旧版对标签外输出的整份拒绝。生成提示仍引导只输出规划，但注入不依赖模型完全遵守这一输出限制。提取不能补回规划中遗漏的要求。


### 0.4.0-dev.21 协作分工提示词

规划与正文阶段改用协作交接说明，替换旧的强制输出引导。问题逐项回答；非问题式引导先原文复述，再单独给出本轮安排，保留作用对象、数值、条件与否定关系。正文沿用原预设成品要求，规划不替代原始资料。原有默认规划/正文指令自动迁移，自定义值保留。标签提取行为不变。

替换前的两个默认字段及完整组装结果备份于 [docs/prompt-backups/0.4.0-dev.20.json](docs/prompt-backups/0.4.0-dev.20.json)，仅包含内置提示词，不包含用户聊天或密钥。自动测试验证迁移及组装，不代表模型已完成实际生成效果验证。


### 0.4.0-dev.22 简化规划指导

移除面向模型的变量宏解释，直接要求问题逐项回答，非问题式指导先逐字复述原文，再单独写本轮安排，安排不能替代原文。宏处理逻辑不变。替换前完整提示词备份于 docs/prompt-backups/0.4.0-dev.21.json；这次仅验证提示词组装，没有验证实际模型的漏项率是否改善。


### 0.4.0-dev.23 六条交接规则

按用户提供的文案拆分问题回答与非问题式指导原文复述，强调一字不差、原文和本轮安排分行；保留条件步骤、资料召回、格式确认及动态规划标签。旧默认开场自动迁移，自定义值保留，正文引导及提取行为不变。替换前提示词备份于 docs/prompt-backups/0.4.0-dev.22.json。未进行真实模型生成效果测试。
