# 创作规划

独立选择预设、世界书和兼容插件资料，调用规划 API 生成公开写作规划，再将规划加入本轮正文请求。正文保留酒馆原配置中的状态栏等要求。

**测试仓库当前提供 0.4.0-dev.4 开发预览，不是正式发布版。** 新输入密钥已支持本机浏览器持久保存，API 方案选择会恢复；真实酒馆 1.18.0 API 联调尚未完成。正式仓库未同步本次更新。

## 界面与方案

从魔法棒菜单打开「创作规划」。右上角齿轮进入设置，太阳按钮切换跟随酒馆/亮色/暗色。

- 设置：选择酒馆当前连接、预设更新编辑器的只读 API 方案，或创作规划自有方案；设置输出额度、超时、插件兼容和楼内显示。
- API 方案：可复制已有密钥引用为本地方案，独立新建/覆盖/删除，不修改编辑器原方案；删除方案不删除共享密钥。新密钥单独存入 IndexedDB，方案只保存随机引用；留空覆盖时保留原密钥。打开面板和刷新后恢复上次选择；删除当前方案或密钥失效时要求重新选择/填写，不自动回退到酒馆连接。
- 预设：选择酒馆预设，显示柏宝箱分组与条目正文，保存独立开关方案。视觉分组不改变 prompt_order 的实际执行顺序。
- 世界书：显示全局、角色主/额外、聊天专属和用户角色世界书；可额外添加世界书，查看正文并保存书/条目开关方案。开启只表示参与扫描，不表示强制注入。
- 楼内显示：规划存入消息 extra，按 swipe 绑定，在独立 iframe 内折叠展示，不追加到 mes，不作为后续对话历史发送；编辑正文后标为历史规划。

界面拥有独立 document 和 CSS，只从酒馆接收 `--SmartThemeBorderColor`、`--SmartThemeBlurTintColor`、`--SmartThemeBodyColor`、`--mainFontFamily`、`--monoFontFamily`。这是样式隔离，不是防御同源恶意插件的安全边界。

## 独立生成

插件冻结来源副本，使用本地开关和私有宏变量构造规划请求。标签取规划预设，歧义时停止并支持手动指定。正文请求只追加规划与正文引导，不把规划预设覆盖到正文预设。规划失败、超时、取消或切换聊天时停止正文，避免沿用旧规划。

兼容资料：柏宝书历史/状态/时间提示/向量召回注入；构画大纲/事件线/刻度注入。柏宝书参数宏通过公开只读 API 按需查询；未勾选时不读取宏资料。不会额外触发插件生成。

世界书使用从 SillyTavern 1.18.0 提取并隔离的扫描核心，保留主次关键词、常驻、递归、概率、预算、扫描深度、分组和计时语义。计时只保存到规划端私有 metadata；不调用宿主全局扫描事件。

## 当前限制

- 酒馆 1.18.0 的 `/api/secrets/write` 保存新密钥时必定激活该密钥。为避免影响正文连接，本开发版不调用此接口，也不使用先切换再恢复的方式。新密钥存于当前浏览器、当前网站地址的 IndexedDB，不随酒馆设置备份同步到其他浏览器/设备；清除网站数据会删除它。它不是加密保险箱，同源脚本及有权限访问浏览器数据的人仍可能读取。插件不把密钥返回到界面快照或写入方案设置。
- 当前连接仅接入已核对的 OpenAI-compatible 返回路径（custom/openai/openrouter/groq/deepseek）；外部方案仅支持 custom。其他连接明确报错。
- 独立组装暂未支持群聊角色轮换和原生附件转换，发现时停止；quiet、impersonate、continue 和工具轮次不触发规划。
- 世界书作者注释/示例/outlet 位置、向量扫描、自动化和角色标签过滤暂未完成独立适配，选中相关项时明确报错，不静默改成普通注入。世界书正则和其他插件的 WORLDINFO_SCAN_DONE 钩子不复用。
- 宏覆盖目前为已验证的基础角色/用户/历史值、变量读写及柏宝书宏；不运行任意全局宏处理器或 EJS。未知宏会阻断，不能宣称兼容所有预设。
- 已有计划若使用不同模型，其真实 token 计算与模型最大上下文仍需实机核验；开发版使用所选预设额度及酒馆当前 tokenizer。

## 验证和开发

`npm test` 运行 Node 测试；`npm run check` 检查全部 src 模块。`tests/browser-check.mjs` 用本地模拟酒馆和假 API 检查三页交互、完整规划/正文分离、楼内绑定、HTML 文本安全、明暗主题、CSS 隔离和 390px 窄屏。

这些测试不代替真实酒馆 API 联调。私人预设仅在本机验证，没有纳入仓库。源码全部位于 `src`，文件头说明作用；`index.js` 为薄入口，`tests` 不参与运行。
