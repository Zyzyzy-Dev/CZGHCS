# 0.4.0 核对记录

## 密钥存储

SillyTavern tag `1.18.0` 的 `src/endpoints/secrets.js`，`SecretManager.writeSecret` 先停用同 key 的所有凭据，再写入 `active: true` 新凭据；`/write` 没有 inactive 参数。不能用保存后 rotate 恢复模拟无副作用保存。

已有密钥可通过请求级 `secret_id` 使用（已核对 `src/endpoints/backends/chat-completions.js`）。本地方案可复制原生引用，删除方案不删除原生密钥。用户于 2026-10-08 明确要求刷新后保留新密钥与方案选择：新密钥写入浏览器 IndexedDB，方案仅存 keyRef。请求使用独立 Authorization，并传不存在于原生密钥库的 czgh-local 前缀引用，防止使用活动密钥。1.18.0 的 custom 路径允许无原生密钥，并在生成和模型列表请求中将自定义头合并到默认头之后。删除最后一个引用该本地密钥的方案时清理密钥。

源码地址：https://github.com/SillyTavern/SillyTavern/blob/1.18.0/src/endpoints/secrets.js

## 移动端修复（0.4.0-dev.3）

统一兼容缺少 crypto.randomUUID 的环境，覆盖界面 RPC、资料快照、方案、密钥引用和规划请求。关闭使用独立的来源校验消息，不排队等待资料读取。浏览器测试禁用 randomUUID 后完成全流程，并模拟资料读取挂起后立即关闭。外层弹窗与 iframe 一并圆角裁切；窄屏检查保留五项主题白名单。
